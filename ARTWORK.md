# Sixzee artwork direction

The theme comes from `assets/safari-knights-reference.jpg`: three knights standing together in a safari landscape.

Usage:

- `sixzee.css` layers a dark teal gradient over the image and uses it as a fixed background, keeping the center readable for dice and scorecards.
- Palette: deep teal `#06171f`, gold `#f4bb3f`, ivory `#f6ead0`, and mint `#5fe0d0`.
- UI motif: 8-bit/pixel type (Press Start 2P + VT323), ivory dice with dark pips, gold held-die highlight.

The original supplied JPEG is kept in `assets/` as the source of truth. Generated backgrounds/social cards were not created because image credits were unavailable; the reference itself is used directly in CSS and social meta tags.
